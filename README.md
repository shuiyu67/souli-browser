# 腕上JM · 搜哩浏览器（Vela 手环浏览器）

> 一款跑在 **Vela 快应用手环**（watch 设备）上的轻量网页浏览器。
> 包名：`com.xinflow.browser` ｜ 版本：`1.0.0` ｜ 平台：`Vela`（`minPlatformVersion 1000`）

手环没有 WebView，本应用采用「拉取网页 HTML → 解析排版」的方式，把网页内容塞进那块小屏，让你在手腕上也能看新闻、查资料、逛静态站。

---

## 📌 功能特性

| 功能 | 说明 |
| --- | --- |
| **网址直连浏览** | 顶部输入网址回车即开，静态 / SSR 站点无需任何设置 |
| **收藏夹** | 常用站点一键收藏，随时回看 |
| **离线页** | 把页面缓存到手环本地，没网也能翻 |
| **关于页** | 版本信息与使用说明 |
| **JS 渲染代理（可选进阶）** | 现代网页多为 JS 动态生成，直连只能拿到空壳。开启后请求经**服务器端无头浏览器（Chromium）**执行 JS、渲染真实内容再回传 |

### JS 渲染代理说明

- **默认关闭 = 直连**：普通站点（静态 / SSR）直接浏览，完全不依赖代理服务器，零门槛。
- **按需开启**：仅当你要访问「必须 JS 才能出内容」的站点时，才需要开启。
- **验证码仅存本机**：在「设置」页填入 5 位代理验证码即可启用，验证码只保存在手环本地 `storage`，**不上传、不随账号同步**。
- **失败自动回退**：代理不可用时自动回退直连，不会甩 401 阻断正常浏览。

## 🚀 使用方式

1. 安装构建产物 `dist/com.xinflow.browser.debug.1.0.0.rpk`（经快应用调试器 / 手环安装器）。
2. 打开应用 → 顶部输入网址 → 回车即可浏览。
3. 遇到需要 JS 的站点：
   - 首页进入「**设置**」→ 填入你的 **5 位代理验证码** → 开启「**启用 JS 渲染代理**」开关。
   - 验证码由你所在的代理服务方提供，仅保存在本机。

## 🛠 开发 & 构建

基于 [Vela 快应用](https://iot.mi.com/vela/quickapp) 技术栈，使用 `aiot-toolkit` 构建。

```bash
# 1. 安装依赖
npm install

# 2. 本地开发（带 watch 热更新）
npm start

# 3. 构建
npm run build

# 4. 产出可安装 rpk（release 包）
npm run release
```

- 调试：`npm run watch`
- 代码规范化（提交前校验 / 格式化 / commit 信息校验）：
  - macOS / Linux：`sh husky.sh`
  - Windows：`./husky.sh`

构建产物：
- `build/`：调试构建目录
- `dist/com.xinflow.browser.debug.1.0.0.rpk`：可安装的调试版 rpk

## 📂 目录结构

```
src/
├── app.ux                    # 应用入口与全局逻辑

    ├── index/               # 浏览页（直连 / 代理调度核心）
    ├── detail/              # 详情页
    ├── offline/             # 离线缓存页

    └── settings/            # 代理设置（验证码 + 开关，存本机）
```

## ⚠️ 注意事项

- 小屏浏览体验有限，**适合文字类内容**（新闻、文档、查询页），不适合复杂交互站。
- **JS 渲染代理为可选进阶功能**，需要兼容的代理服务支持；普通浏览不依赖它。
- 代理验证码为 **5 位数字**，方便在小屏键盘输入。
- `system.webview` 已在 manifest 声明，但手环实际无 WebView，内容由应用自行解析渲染。
